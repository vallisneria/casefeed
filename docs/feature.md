# 기능 목록

## 버전 규칙

[시맨틱 버저닝](https://semver.org/lang/ko/)을 따릅니다. 기준이 되는 공개 인터페이스는 다음과 같습니다.

- RSS 피드: 도메인과 경로, GUID 형식, 링크 서비스 파라미터
- 조회 API: 엔드포인트, JSON 스키마 (2.0.0부터)

| 변경 | 버전 |
|---|---|
| 공개 인터페이스의 하위호환이 깨짐 (경로·도메인 변경, GUID 형식 변경, 스키마 필드 삭제 등) | MAJOR |
| 하위호환을 유지하는 기능 추가 (새 피드, 새 엔드포인트, 스키마 필드 추가, 내부 기능 추가) | MINOR |
| 버그 수정, 수집기 대응 수정 | PATCH |

## v1.0 (완료)

- **판례공보 RSS 피드**: 대법원(`/대법원/판례공보`), 헌법재판소(`/헌법재판소/판례공보`)
  - 판례를 수집한 시각 기준 최신순. 선고일이 아니라 수집 시각을 쓰는 이유는 늦게 공개된 판례도 구독자에게 새 항목으로 보이게 하기 위함
  - GUID는 `법원명_사건번호`로 고정 (리더 중복 방지, 바꾸면 기존 구독자에게 중복 표시됨)
  - 판례 링크 서비스 선택 가능(케이스노트·엘박스·빅케이스). 파라미터는 안내 페이지 참고
- **안내 페이지**: 서비스 소개와 피드 사용법
- **자동 수집**: 사법정보포털·헌법재판소에서 일정 시간마다 새 판례 수집

## v1.1 (예정): 수집 안정화, 라이선스 변경

- **수집 실패 기록 및 재수집**: 판례 수집에 실패하면 기록하고 다시 수집
- **라이선스 변경**: AGPL-3.0-or-later로 변경. 단, 범용 라이브러리인 `court-api`는 다른 프로젝트에서 쓰기 쉽도록 MIT OR Apache-2.0으로 배포

## v1.2 (예정): 판례 전문 수집

공개 인터페이스는 바뀌지 않습니다. v2.0에서 판례를 열람할 수 있도록 데이터를 미리 쌓아 둡니다.

- **판례 전문 수집**: 외부 링크 없이 서비스 내에서 판례 전문을 읽을 수 있도록 판례 전문 수집
- **판례 본문을 일관된 형식으로 정리**: 어느 화면에서든 판례가 같은 모양으로 보이고, 다른 서비스에서도 재사용할 수 있게 일관된 JSON 스키마로 정리. 이 단계에서는 내부용

## v2.0 (예정): 신규 도메인, 판례 검색과 열람

신규 도메인으로 옮기며 RSS 피드 경로가 바뀌므로 MAJOR 버전입니다. 범위가 크므로 pre-release로 나눠 진행합니다.

- `2.0.0-alpha`: 조회 API
- `2.0.0-beta`: 웹 프론트엔드, 판례 검색
- `2.0.0`: RSS 경로 확정, 기존 도메인 리다이렉트, 이용약관

기능:

- **조회 API**: 서비스에서 수집한 개별 판례를 v1.2의 JSON 스키마로 조회하는 API를 만들어 모두가 사용할 수 있게 하고, 캐시를 길게 잡음
- **웹 프론트엔드**: 외부 사이트의 상태와 무관하게 작동할 수 있도록 판례를 열람할 수 있는 독자 프론트엔드를 제작
- **판례 검색**: 프론트엔드에서 사건번호, 사건명 등으로 판례를 찾아 열람할 수 있게 함. 캐시하기 어려운 동적 요청이므로 rate limit 적용
- **RSS 피드 이전**: v1의 RSS 피드는 계속 존재해야 함. GUID는 유지하고 URL 경로는 프론트엔드 경로를 먼저 구성한 후 변경
  - 신규 도메인을 구매해 호스팅할 예정이므로 경로 하위호환을 챙길 필요 없음. 신규 RSS 피드의 경로가 확정되면 기존 도메인에서 일정 기간 리다이렉트
- **이용약관 및 면책 고지**: 코드 라이선스는 서비스(사이트·RSS·API) 이용자에게 적용되지 않으므로 서비스용 고지를 별도로 마련

## v2.1 (예정): 과거 판례

- **과거 판례 소급 수집**: 인용 그래프가 과거 판례를 가리켜도 사이트 내에서 문제없이 열람할 수 있도록 과거 판례를 소급해 수집

## v2.2 (예정): 법령

- **법령 수집**: 판례의 기반이 되는 법률, 시행령, 시행규칙을 수집
- **법령 열람**: 프론트엔드와 조회 API에 법령 추가

## v2.3 (예정): 인용 그래프

- **법령 및 판례 인용 그래프**: 법률 학습자에게 판례와 판례, 판례와 법률 간의 관계를 보다 쉽게 보여주도록 인용 그래프 형태로 저장하고 표시
